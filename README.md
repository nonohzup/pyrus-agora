# Pyrus Agora

Pyrus Agoraは、ソーシャルVR向けの時間通貨型パフォーマンスイベント企画です。
参加者は限られたトークンを使い、屋台形式で並ぶ多彩なパフォーマーの中から「自分の時間を誰に使うか」を選択します。

本リポジトリは企画書とガイドラインを公開し、誰でも派生イベントを開催できる形で提供します。

## 概要

ソーシャルVRのパフォーマンスシーンが成熟する中で、推し文化中心の構造が強まり、新規のパフォーマーや異ジャンルの才能が発見されにくくなっています。Pyrus Agoraは、参加者の時間という有限資源を可視化し、「知らない才能との出会い」を意図的に設計することを目的としたイベント企画です。

名前の由来は「火の広場」(ラテン語 Pyrus + ギリシャ語 Agora)。一点集中の劇場ではなく、複数の視線が交差する広場として設計されています。

## 基本構造

### 時間と進行

- 開催時間は1時間
- 3ラウンド構成(1ラウンド = 15分上演 + 5分休憩)
- 3つのラウンドは「朝」「昼」「夕」として、ワールドの明るさや空の色が変化する

### トークン

- 参加者は入場時に一定量のトークンを受け取る
- イベント終了時にトークンは消滅(持ち越し不可)
- トークンの正式名称は固定(シリーズ共通)、見た目は各開催の世界観に応じて自由
- 例:火種、氷の結晶、花びら、星屑など

### 屋台

- パフォーマーは「屋台」として出展する
- 物理的な人数制限なし(アバター非表示機能を活用)
- ジャンルは不問(ダンス、バーテンディング、朗読、占い、パーティクルショーなど)

### 発見促進の仕掛け

- 第1ラウンドは「初訪問の屋台」にしか使えないトークンを配布
- ブラインド屋台(出演者名を伏せた状態で出演する屋台)を一定数用意
- 最終ラウンドは「これまで訪れた屋台から選ぶ」推し決定ラウンド

詳細は `docs/` 以下のドキュメントを参照してください(順次追加予定)。

## プラットフォーム

VRChat、Resoniteなど、ソーシャルVRプラットフォーム全般を想定しています。
特定のプラットフォームに依存しない設計を目指します。

## ステータス

現在、企画策定段階です。第1回開催に向けて、人選やワールド製作者の選定を時間をかけて進めます。

## 派生イベントについて

Pyrus Agoraは派生イベントを歓迎します。本リポジトリの企画書を参照し、独自の世界観や運営方針で開催することができます。

詳細は `CONTRIBUTING.md` を参照してください(順次追加予定)。
